# Як я працюю з AI

[Відкрити анкету](https://genkovich.github.io/ai-work-check/)

10 запитань про розробку з AI. Під кожним є навчальне пояснення на прикладі застосунку зі списком покупок.

Обери відповіді й отримай таблицю та одну наступну дію. Бали описують звички за самооцінкою, не рівень розробника. Відповіді обробляються у браузері й не надсилаються автору. Немає реєстрації, аналітики чи автоматичного збереження відповідей.

Результат можна завантажити текстом або у файлі для повторного проходження. Перший результат залишається окремим від нових відповідей.

## Перевірка

`node --test test/first-step.check.mjs`

Сторінка складається з одного самодостатнього `index.html`. GitHub Pages публікує корінь гілки `main`; `.nojekyll` вимикає обробку Jekyll. В репозиторії тільки анкета, її текстова версія й перевірки.
