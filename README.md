# Як я працюю з AI

Дві анкети мінікурсу з Agentic Engineering. Кожна це один HTML без залежностей.

- [Стартова: 10 запитань](https://genkovich.github.io/ai-work-check/), урок 1. Запитання про практики роботи з AI, яких курс і вчить, тому низький результат на старті очікуваний. Під кожним коротка підказка на прикладі застосунку зі списком покупок.
- [Фінальна: 35 запитань](https://genkovich.github.io/ai-work-check/final.html), урок 6. Складніші запитання про роботу з агентами, по сім на кожен стик. Результат додає блок «Сильні й слабкі стики»: що сильне, що посередині, що слабке.

Запитання йдуть по ланцюгу курсу (Intent, Context, Spec, Plan, Implementation, Verification, Learning), стики між ланками ті самі на обох сторінках. Результат показує найслабший стик, урок, який його розбирає, і одну звичку для наступної спроби. Бали описують звички за самооцінкою, не рівень розробника. Імпорту між анкетами немає: стартовий Markdown можна покласти поруч із фінальним і порівняти стики.

Відповіді обробляються у браузері й не надсилаються автору. Немає реєстрації, аналітики чи автоматичного збереження. Результат можна завантажити текстом або як `result.json` (старт) чи `result-final.json` (фінал).

## Як це зібрано

`index.html` це єдине джерело стилів, рушія і обох наборів запитань; сторінка обирає набір за `data-mode` на `<html>`. `final.html` збирається з нього, а копії для пакета учасника лежать в іншому репозиторії:

```sh
node build.mjs                                        # index.html → final.html
node build.mjs --kit ../agentic-engineering-mini-kit  # плюс first-step.html, final-step.html, шаблони й тест пакета
```

Текстові версії `questionnaire.md` і `final-questionnaire.md` правляться рукою; тести перевіряють, що запитання в них ті самі, що в HTML.

## Перевірка

```sh
node --test test/first-step.check.mjs
```

GitHub Pages публікує корінь гілки `main`; `.nojekyll` вимикає обробку Jekyll. Опис репозиторію на GitHub оновлюється командою `gh repo edit --description '<опис>'`.

## Практика другого уроку

[Контекст, з яким можна продовжити роботу](https://genkovich.github.io/ai-work-check/context-check.html): десять послідовних кроків із командами, промптами й підказками. Матеріали для роботи лежать у поточному приватному кіті курсу; ця сторінка не надає доступу до нього й не публікує весь курс.

`context-check.html` працює самостійно, без залежностей або API. Зберігати десять відміток у браузері можна лише за власним вибором; текст документів і результати команд сторінка не збирає. Є Markdown-експорт відміток, які не є доказом виконання перевірок.

Перевірка сторінки: `node --test test/context-check.check.mjs`. Звірка посилань на файли та тверджень про код додатково виконується в приватному кіті: `node --test test/context-check.check.js`.
