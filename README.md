# Як я працюю з AI

[Відкрити анкету](https://genkovich.github.io/ai-work-check/)

Стартова анкета мінікурсу з Agentic Engineering: 10 запитань про розробку з AI. Під кожним є коротка підказка на прикладі застосунку зі списком покупок.

Запитання йдуть по ланцюгу курсу (Intent, Context, Spec, Plan, Implementation, Verification, Learning), по два на кожен стик між ланками. Результат показує найслабший стик, урок, який його розбирає, і одну звичку для наступної спроби. Бали описують звички за самооцінкою, не рівень розробника.

Відповіді обробляються у браузері й не надсилаються автору. Немає реєстрації, аналітики чи автоматичного збереження. Результат можна завантажити текстом або як `result.json`: цей файл знадобиться у фінальній анкеті наприкінці курсу.

## Перевірка

`node --test test/first-step.check.mjs`

Анкета першого уроку міститься в самодостатньому `index.html`. GitHub Pages публікує корінь гілки `main`; `.nojekyll` вимикає обробку Jekyll.

## Практика другого уроку

[Context Engineering: перевіряємо контекст проєкту](https://genkovich.github.io/ai-work-check/context-check.html): десять кроків із командами й підказками. Читаємо готові основні та вкладені інструкції, створюємо карту через survey і перевіряємо нову сесію агента. Єдина політика даних має короткі адаптери Claude Code та Cursor; для Codex передбачено явне читання через основні інструкції. Матеріали для роботи лежать у приватному кіті курсу; ця сторінка не надає доступу до нього й не публікує весь курс.

`context-check.html` працює самостійно, без залежностей або API. Зберігати десять позначок у браузері можна лише за власним вибором. Чотири поля дозволяють записати свій інструмент, фактичні запуски, результат нової сесії та неперевірене. Ці тексти залишаються у відкритій вкладці й не зберігаються автоматично, навіть коли ввімкнено збереження позначок. До закриття сторінки завантаж `lesson-2-context-result.md`: він містить позначки й власні записи, але не є автоматичним доказом виконання команд. Дані полів не надсилаються автору; секрети й приватні розмови сюди не вставляй. Старі позначки попередньої вправи не переносяться, бо маршрут змінився.

Перевірка сторінки: `node --test test/context-check.check.mjs`. Звірка посилань на файли та тверджень про код додатково виконується в приватному кіті: `node --test test/context-check.check.js`.
